# Prerequisites — Startup Product & GTM track

**Role level:** 30 (deep functional pillar — Startup family)
**Track:** `startup-product-gtm-curriculum`

This track is the **deep functional pillar** for the customer-facing branch of the startup dependency graph. It assumes the learner already has the Foundations mental model installed and is ready to go deep on Discovery → PMF → Positioning → ICP → Founder-Led Sales → Pricing → Sales Motion → Demand Gen → Retention & Expansion → GTM Metrics & First Hires. The ten modules move a learner from an IDEA-stage discovery interview to a Series-A-boundary metrics one-pager and first-hire staging plan.

## Assumed lower-level curriculum

- **[`startup-foundations`](https://github.com/ai-startup-curriculum/startup-foundations)** (level 10) — required. Foundations owns the *system* (what a startup is), the *graph* (customer-facing / corporate-structure / economics branches), the *stages* (IDEA → PRE-SEED → SEED → SERIES-A → GROWTH → MATURE), the founder's operating loop (decide → allocate → communicate → measure), and the founder-numbers slice (runway, burn, growth read, default alive / default dead, North-Star metric selection). This track *never* re-teaches those; every module references back. If you have not completed Foundations, start there — this track will feel over-scoped and under-anchored without it.

## Assumed working knowledge

Even after Foundations, you should be practically comfortable with:

- **Reading long-form practitioner writing critically** — Paul Graham essays, First Round Review pieces, SaaStr posts, April Dunford talks, Andy Raskin narratives. You should be able to pull the underlying argument out of a positioning talk or a founder-led-sales post without being carried by the prose.
- **Basic spreadsheet fluency for cohort analysis** — enough to build a monthly cohort retention table, a CAC-by-channel breakdown, and a fully-loaded CAC / LTV / payback calculation in mod-102, mod-109, and mod-110. Google Sheets, Excel, or Numbers are all fine.
- **Comfort with a CRM abstraction** — an opportunity, a stage, a next step, a close date, a weighted forecast. mod-105 (founder-led sales) and mod-107 (motion design) both use a CRM (a spreadsheet is a fine substitute) as the artifact through which the motion runs.
- **Ability to write a one-page memo and a strategic-narrative deck** — mod-103 (positioning) and mod-105 (founder-led sales) both ship written and slide artifacts. If you have never authored a strategic-narrative deck, plan to spend extra time on the mod-103 lab.
- **Willingness to run live customer conversations** — mod-101 (discovery) and mod-105 (founder-led sales) both require live conversations with real prospects. The 'do things that don't scale' anti-analytic hand-work is not optional at this stage.
- **Willingness to work against a real (or realistic hypothetical) startup with a specific ICP and product surface** — every module has exercises and every project has a deliverable that only becomes concrete when applied to one company. Pick one before starting mod-101 and use it end-to-end.

## Not assumed, taught here

You do **not** need prior experience with:

- Any specific customer-discovery framework — Steve Blank's customer development, the Mom Test, JTBD / Outcome-Driven Innovation. mod-101 covers each at the operating level.
- Any specific PMF measurement instrument — the Sean Ellis 40% survey, cohort retention curve reading, the Superhuman iteration engine. mod-102 walks each end-to-end.
- Any specific positioning framework — the April Dunford five-component frame, the Andy Raskin strategic-narrative shape, the Moore Crossing-the-Chasm beachhead frame. mod-103 covers each with drills against real product pages.
- Any specific founder-led sales operating model — the Kazanjy founding-sales stage model, next-step discipline, weekly-forecast honesty. mod-105 covers the full end-to-end motion.
- Any specific sales qualification framework — SPICED (Winning by Design), MEDDIC / MEDDPICC. mod-105 and mod-107 cover each and prescribe when to use which.
- Any specific pricing methodology — Van Westendorp, Gabor-Granger, value-based pricing, good / better / best packaging. mod-106 covers each with runnable drills.
- Any specific PLG motion design — activation events, product-qualified leads, sales-assist triggers per Wes Bush / OpenView. mod-107 covers each.
- Any specific growth-loops framing — Balfour / Reforge growth loops as a replacement for the AARRR funnel where the loop applies. mod-109 covers each with diagnosis drills.
- Any specific GTM benchmark set — OpenView / SaaStr / Skok benchmarks for CAC / LTV / payback / magic number / NRR / GRR by ARR band. mod-110 covers each.

## Recommended reading before starting

- **Discovery + PMF canon:** [Rob Fitzpatrick — *The Mom Test* companion](https://www.momtestbook.com/), [Steve Blank — *The Four Steps to the Epiphany* (Stanford PDF)](https://web.stanford.edu/group/e145/cgi-bin/spring/upload/handouts/Four_Steps.pdf), [Rahul Vohra — 'How Superhuman Built an Engine to Find PMF' (First Round Review)](https://review.firstround.com/how-superhuman-built-an-engine-to-find-product-market-fit/).
- **Positioning canon:** [April Dunford — Obviously Awesome companion](https://www.aprildunford.com/obviously-awesome), [Andy Raskin — 'The Greatest Sales Deck I've Ever Seen'](https://medium.com/the-mission/the-greatest-sales-deck-ive-ever-seen-4f4ef3391ba0).
- **Founder-led sales canon:** [Pete Kazanjy — *Founding Sales* (full text)](https://www.foundingsales.com/) — at minimum, read the first three chapters before mod-105.
- **Growth + metrics canon:** [David Skok — SaaS Metrics 2.0](https://www.forentrepreneurs.com/saas-metrics-2/), [Brian Balfour / Reforge — Growth Loops](https://www.reforge.com/blog/growth-loops), [Andrew Chen — retention essays](https://andrewchen.com/essays/).
- **Paul Graham anchors from Foundations, re-read as this track's operating traditions:** ['Do Things That Don't Scale'](https://paulgraham.com/ds.html) and ['Startup = Growth'](https://paulgraham.com/growth.html).

## Not required, useful to have

- **Prior founder or founding-team GTM exposure** — a first sales / marketing hire seat at a pre-Series-A startup, a founder-in-residence rotation, or a chief-of-staff-to-founder role with GTM scope. This track does not require it but the exercises are richer against a real context.
- **Prior product-marketing exposure** — familiarity with a positioning brief, a launch narrative, or a competitive-alternatives grid. mod-103 assumes zero exposure but you will move faster if you have some.
- **Prior CRM administration experience** — Salesforce, HubSpot, Attio, or a lightweight tool. mod-105 and mod-107 use a spreadsheet as the CRM stand-in; a real CRM background makes the artifact modelling faster.
- **Familiarity with a modern product-analytics tool** — Amplitude, Mixpanel, PostHog. mod-102 and mod-109 use the vocabulary; hands-on exposure lets you skip the tool-onboarding overhead.

## Not in scope for this track (linked out)

- **The startup-as-a-system mental model, the dependency graph, the stage axis, the founder's operating loop, and the founder-numbers slice** — owned by [`startup-foundations`](https://github.com/ai-startup-curriculum/startup-foundations) (level 10). Prerequisite; *never* re-taught here.
- **Product-management depth** — feature prioritisation frameworks (RICE / MoSCoW / opportunity solution tree), roadmap discipline, product-ops, design systems, product-analytics tooling — owned by [`cpo-curriculum`](https://github.com/ai-startup-curriculum/cpo-curriculum). This track covers the *market-facing* discovery / PMF / positioning half; the *shipping-facing* prioritisation / roadmap half lives there.
- **Unit-economics deep-dive beyond the GTM operator view** — cohort financial modelling, capital-allocation frameworks, LTV discount-rate math, Series-A fundraising narratives that turn GTM traction into a priced round — owned by [`startup-finance-fundraising-curriculum`](https://github.com/ai-startup-curriculum/startup-finance-fundraising-curriculum) (level 20). This track uses the operator view (CAC, LTV, payback, magic number, NRR as GTM instruments); the fundraising depth lives there.
- **GTM-org hiring / comp / IC-plan / management depth** — quota carrying-rep comp structures, sales-comp legal, employment contracts — owned by [`startup-operations-governance-curriculum`](https://github.com/ai-startup-curriculum/startup-operations-governance-curriculum) (level 25). This track covers the *staging* logic (which hire when, based on what GTM signal); the *comp* structures defer there.
- **Board-facing GTM narrative at the CEO level** — [`founder-ceo-curriculum`](https://github.com/ai-startup-curriculum/founder-ceo-curriculum) (level 30) is the sideways role-pathway peer that references this curriculum for GTM depth at ~60% coverage and adds CEO-level framing.
- **Exit and endgame** — [`startup-exit-curriculum`](https://github.com/ai-startup-curriculum/startup-exit-curriculum) (level 40). This track produces the GTM traction numbers; that track packages them for the acquirer / underwriter.
- **Legal opinion** — out of scope; route to counsel.
- **Personal tax / immigration / accounting** — out of scope; route to a qualified professional.
