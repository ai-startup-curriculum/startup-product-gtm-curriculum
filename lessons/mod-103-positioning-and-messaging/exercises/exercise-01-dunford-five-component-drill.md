# Exercise 01 — Dunford Five-Component Drill

**Estimated time:** 3 hours
**Chapter links:** [`01-positioning-vs-messaging.md`](../01-positioning-vs-messaging.md), [`02-dunford-five-components.md`](../02-dunford-five-components.md)
**Prerequisite reading:** [April Dunford — *Obviously Awesome* (2019)](https://www.aprildunford.com/obviously-awesome), Chapters 1-3 (~90 min); [April Dunford — "The 5 Building Blocks of Positioning" (blog)](https://www.aprildunford.com/blog) (~15 min)

## Problem statement

Chapter 2 named the five components of the Dunford positioning frame — competitive alternatives, unique attributes, value (derived from attributes), best-for characteristics, market category — and specified that each component has a **default answer** the frame is designed to reject. This exercise trains you to author a defensible five-component positioning against the default failure modes, and to pressure-test the authoring against three named competitive alternatives (per Chapter 7's ship discipline).

You will produce a **defensible five-component positioning** for one real (or realistic hypothetical) startup, then pressure-test it against three named competitive alternatives.

This exercise is the seed of the ship artifact in Chapter 7. Exercise 06 will derive the product-page hero from what you author here; the module lab will bundle this authoring, the Exercise 03 narrative deck, and the Exercise 06 hero into the shipped artifact set.

## Requirements

Deliver a folder `exercise-01/` with:

- `part-a-startup-brief.md` — the startup you're positioning + the raw material you're working from.
- `part-b-five-components.md` — the defended five-component positioning.
- `part-c-pressure-test.md` — the three-alternative defence.

### Part A — Pick the startup and gather the raw material (30 min)

Pick one of the following:

- **Your own startup** (preferred) — you have the raw material already.
- **A public startup** whose product page and pitch deck are accessible enough to author against — Y Combinator batch companies, publicly-launched startups with case-study depth on First Round Review or Lenny's Newsletter.
- **The running Loomly example from the chapters** — extend it, don't just re-state it.

Whichever you pick, produce `part-a-startup-brief.md` containing:

- Startup name (or working name).
- One-paragraph description in *your own words* — not marketing copy.
- Current product surface (features shipped today; what a user can do).
- Current customer base (if any) — number, segment, ARR band.
- **Raw material** — either (a) 5+ actual customer conversation notes with the *"what would you do without our product?"* question asked verbatim, or (b) if the startup is pre-customer or you don't have access to customers, 5+ realistic simulated buyer interviews that name specific alternatives. Simulated interviews must be labeled clearly and must draw on real segment knowledge — do not invent buyers that don't exist.

If your startup has no customers and you cannot simulate buyer interviews from real segment knowledge, pick a different startup for this exercise. The five-component frame requires Component 1 to be *sourced*; you cannot author it credibly without buyer-adjacent input.

### Part B — Author the five components with defence (90 min)

Deliver `part-b-five-components.md` structured against Chapter 2. For each of the five components, produce **the component** and its **defence** — the specific reason the component rejects its named default.

#### Component 1 — competitive alternatives

- List the alternatives buyers actually named in Part A's raw material. Number each alternative and cite the interview(s) it came from (interview 1, interview 3-5, etc.).
- For each alternative, one line describing the buyer's rationale for using it today.
- **Default rejected:** name the direct competitors from the founder's pitch deck that were *not* named by buyers. Explain in one line why they are not the alternatives.
- **Defence:** show ≥ 3 alternatives that are sourced from ≥ 2 different interviews each (or, if simulated, from ≥ 2 realistic segment perspectives).

#### Component 2 — unique attributes

- List the 3-5 properties your product has that the *named alternatives from Component 1* lack.
- For each attribute, name which specific alternative it is unique against.
- For each attribute, name the product surface (feature / capability / property) that delivers it.
- **Default rejected:** list 3+ features from your marketing page that would fail this test (they are not unique against the named alternatives, or they are table-stakes in the category). One line each on why.
- **Defence:** every attribute is defensible against ≥ 1 named alternative and produced by a real (shipped, not planned) product surface.

#### Component 3 — value (derived)

- For each unique attribute in Component 2, write the attribute → value → buyer-consequence chain in one sentence. Where possible, name a number (cycle-time reduction, cost saving, coverage improvement). If you cite a number, cite the source; if you don't have one, write `<!-- needs-research: [what you need to verify] -->` inline rather than inventing a number.
- **Default rejected:** list 3+ value slogans your team has used that would fail this test (asserted value without traceable attribute — e.g., "we save you time," "we make X easier"). One line each on why the assertion fails.
- **Defence:** every value bullet traces to a named attribute; no slogans.

#### Component 4 — best-for characteristics

- List 3-5 customer characteristics that predict the customer will care most about the value (firmographic, situational, technical, behavioural — mix as appropriate).
- For each characteristic, one sentence naming *why* customers with that characteristic care more than customers without it.
- **Default rejected:** name the "everyone with problem X" over-broad market that a positioning without discipline would default to. One line on why it is too broad.
- **Defence:** every best-for characteristic has a *why* line; the aggregate best-for space is narrower than the TAM.

#### Component 5 — market category

- Name the primary category — the shelf buyers use.
- Name one adjacent category you considered but did not choose, with a one-line reason.
- If you considered category invention, name the four-conditions check (Chapter 2) — long runway, coordinated campaign, replaceable incumbent category, aligned buyer title — and pass / fail each.
- **Default rejected:** the obvious in-industry label the founder inherits without asking. One line on why it is broken (crowded, wrong price band, wrong buyer routing, etc.).
- **Defence:** the primary category is either (a) buyer-recognised (5+ buyers in Part A used or would search for this label) or (b) a category-invention with all four conditions defended.

### Part C — Pressure-test against three named alternatives (60 min)

Deliver `part-c-pressure-test.md`. This is the Chapter 7 pressure-test discipline applied to your authoring.

Pick **three specific alternatives** from your Component 1 list. Ideally include:
- One direct in-category competitor.
- One horizontal / adjacent-category tool used in a specific way.
- One "status quo" alternative (spreadsheet, script, doing nothing).

For each of the three, write a paragraph naming:

1. **The buyer that would rationally choose the alternative over you.** Not "our worst prospect" — the buyer for whom this alternative is genuinely the right choice. Be specific about firmographic, situational, or stage-of-buying-journey traits.
2. **The specific value the alternative offers that you don't.** Do not straw-man; name a real strength.
3. **The specific value you offer that the alternative doesn't.** Traced from your Component 2/3 authoring.
4. **The segment where the trade-off tips in your favour.** Ideally this is your beachhead segment (Chapter 5 / Exercise 05).

Close with a one-paragraph summary:

- Name the segment where you win against all three alternatives.
- Name the segment where you lose against ≥ 1 of the three. If you cannot name a segment where you lose, the pressure test failed — your positioning is claiming to win everywhere, which is the discipline the module explicitly rejects.

## Starter guidance

- Read Chapters 1 and 2 end-to-end before starting. The five-component structure and each component's default-rejection bar are the operating rubric.
- The single most-mis-handled component is Component 1 (competitive alternatives). Founders name the direct in-category competitors from their pitch deck; buyers name the spreadsheet, the script, or the status quo. If your Component 1 list looks like your pitch deck's competitor slide, you have almost certainly authored the default. Re-run the "what would you do without our product?" question against the raw material.
- Component 3 (value) is where slogans creep in. Every value bullet must trace to a Component 2 attribute; if the trace cannot be written, the bullet is aspiration and must be replaced.
- Component 4 (best-for) is where TAM leaks in. "Any B2B company with a sales team" is a TAM, not a best-for. Ask: *of that TAM, what specifically makes some customers care more than others?* Those are the characteristics.
- Component 5 (category) is where founders over-index on invention. Category creation is a multi-year campaign; most startups should file into an existing shelf or shift to an adjacent one. If you're considering invention, defend all four conditions or drop the invention.
- The pressure test in Part C is the point of the exercise. A positioning that claims to win against every alternative for every buyer has not made a choice. Real positioning names both where you win and where you lose — and picking a beachhead requires being honest about the second.
- If any Part B component cannot be defended without inventing a fact, note the gap with `<!-- needs-research: [what you need] -->` rather than glossing. The gap is the exercise's most useful output — it tells you which buyer interview or product-surface confirmation you still owe.
- Do not spend more than 30 minutes on Part A. The heavy lifting is Parts B and C; if you're at the two-hour mark and still gathering raw material, cut and move on with what you have.

## Acceptance criteria

Your submission is complete when:

- [ ] Part A names the startup, produces a self-written description (not marketing copy), and includes ≥ 5 sourced or realistically-simulated buyer inputs with the "what would you do without us?" question asked verbatim.
- [ ] Part B includes all five components in Chapter 2's order, each with (a) the component itself, (b) the specific default it rejects with one line on why, (c) the defence that shows the component is defensible against its default.
- [ ] Component 1 names ≥ 3 alternatives sourced from ≥ 2 different interviews / segment perspectives each. The direct-competitor default is named and explicitly rejected.
- [ ] Component 2 names 3-5 attributes; each is unique against a *specifically-named* alternative from Component 1; each is delivered by a *shipped* product surface. The marketing-feature-list default is named and rejected.
- [ ] Component 3 has one value bullet per attribute, each traced as attribute → consequence. The slogans default is named with 3+ examples of slogans that were rejected. Any unsourced numbers are marked with `needs-research`.
- [ ] Component 4 has 3-5 best-for characteristics with a *why* line each. The "everyone with problem X" default is named and rejected.
- [ ] Component 5 names the primary category, an adjacent-considered category with a reason for not choosing it, and (if category invention was considered) a four-conditions defence.
- [ ] Part C picks three alternatives (ideally spanning direct / horizontal / status-quo), writes a defensible four-part paragraph on each, and closes with a summary that names ≥ 1 segment where you *lose*.
- [ ] No component is a copy-paste of the founder's existing marketing page. If the authoring is identical to the current site, the exercise has not moved the positioning.

## Common ways this exercise goes wrong

- **Copying the current marketing page into the components.** If the "current alternatives" list matches the "competitors" slide of the pitch deck, and the "unique attributes" list matches the marketing-page feature list, the exercise has not moved the positioning. The whole point is to *defend against* those defaults, not restate them.
- **Skipping the raw material.** Authoring Component 1 without buyer interviews (or realistic simulated ones) produces founder-invented alternatives. The frame collapses; every downstream component is uncalibrated.
- **Value bullets as slogans.** "We save you time" without an attribute-consequence chain is not a Component 3 entry; it is decoration. Every value bullet must trace back.
- **Best-for as TAM.** "Any company with a sales team" is not a best-for characteristic. Ask: what specific characteristic predicts *higher* value; then use that.
- **Category invention without the four-conditions defence.** Founders love inventing categories because it feels differentiated. Category creation costs multi-year capital. Defend all four conditions or drop the invention.
- **Pressure-test claims of "we win everywhere."** A positioning that beats all alternatives for all buyers has not made a choice. Real positioning names where you lose.
- **Straw-manning the alternatives in Part C.** Buyers know the incumbent. If you describe the incumbent dishonestly, the pressure test itself becomes non-credible. Name real strengths honestly; then name where the trade-off tips.
- **Not marking unsourced numbers.** If you cited a "40% faster" figure that you cannot trace to a source, mark it with `needs-research`. Untraceable numbers are the fastest way to lose credibility on the ship artifact.
- **Treating the exercise as a workshop artifact.** The output of this exercise is a *decision document*. Chapter 7's dated / signed / versioned discipline applies; put a date at the top of Part B.
