# Exercise 03 — Run Five Live Problem Interviews

**Estimated time:** 4 hours (plus scheduling calendar time)
**Chapter links:** [`01-customer-development-loop.md`](../01-customer-development-loop.md), [`02-mom-test-discipline.md`](../02-mom-test-discipline.md), [`03-do-things-that-dont-scale.md`](../03-do-things-that-dont-scale.md), [`06-discovery-corpus-and-synthesis.md`](../06-discovery-corpus-and-synthesis.md)

## Problem statement

Run **five live problem interviews** — real people, live voice, not asynchronous DM — against the ICP and the v0 script from Exercise 02. Record each in the standard interview-note template from Chapter 6. Write one synthesis memo across the five.

This is the exercise the whole module hinges on. The rest of the exercises operate on artifacts; this one operates on real people. Do it.

## Requirements

Deliver a folder `exercise-03/` under your working folder, containing:

- Five interview note files, one per interviewee, following the Chapter 6 template.
- One synthesis memo across the five interviews (Chapter 6 synthesis template).
- One retrospective memo on the interview process itself.

### 1. Recruit five interviewees

- Use the recruiting channels ranked in Chapter 3: personal network → warm intros → community → cold direct outreach → paid panel. Exhaust each channel before moving to the next.
- All five must plausibly fit the ICP you named in Exercise 02. Screen with one clarifying question before you schedule (Chapter 3).
- If you cannot reach five people who fit the ICP within one week, that itself is a discovery finding — record it in the retro memo (Section 3 below) and continue with as many as you can, but do not water down the ICP to inflate the count.
- **In-person or live-video preferred; phone acceptable; async DM not acceptable** for this exercise. The follow-up-"why?" mechanic (Chapter 2) is the whole point.

### 2. Run and note each interview

For each interview:

- Run the Exercise 02 v0 script. Feel free to skip prepared questions if the conversation is producing better material — the script is a floor, not a ceiling.
- Ask permission to record; if declined, take notes by hand.
- **Write the interview note the same day** using the Chapter 6 template — six sections, editorialising kept in its own section, canonical vocabulary.
- File the note as `notes/YYYY-MM-DD-firstname-role-slug.md` in `exercise-03/`.

### 3. Synthesise across the five

Write one synthesis memo `exercise-03/synthesis-batch-01.md` using the Chapter 6 synthesis template. It must include:

- New signal, confirmed patterns, contradictions.
- **A kill-list** — at least one hypothesis you now believe is dead, with the specific interview IDs that killed it.
- Segment-drift check — are all five interviewees actually the same segment, or did recruiting bias slip in?
- Updated solution-shape hypotheses (even at the problem-interview stage you will have some).
- Questions you would add / drop from the script for the next batch.

### 4. Process retrospective

Write a second short memo `exercise-03/retro.md` (1 page) that scores yourself on the interview discipline:

- **Talk ratio.** Roughly what percentage of the interview did you talk? (Chapter 2: <30% is the target for a problem interview.) If you recorded, listen to a random 3-minute clip and check.
- **Founder-fishing questions you slipped.** Any "would you..." / "do you think..." / "how much would you pay..." questions that leaked into the live conversation despite the v0 script? List them.
- **The best question you asked** — one that produced information you did not expect. Which one, and why did it work?
- **The worst question you asked** — one that produced fluff or a compliment. Which one, and how would you rewrite it?
- **Recruiting channel effectiveness** — which channel(s) actually got you five people? What would you do differently next batch?
- **Commitment-ask conversion** — how many of the five said yes to your commitment-ladder ask? Which ask worked and which did not?

## Starter guidance

- Start recruiting *before* you finish polishing the script. The critical path is calendar time, not script time. Aim to send your first five recruiting messages within 24 hours of starting this exercise.
- If your ICP overlaps with your personal network, do not feel bad about starting there — Chapter 3 explicitly ranks personal network first. Discount for warm-bias by asking past-tense specific questions (Chapter 2) rather than opinion questions.
- Recording a call and transcribing later is worth the setup cost even at n=5. But **write the note the same day** — do not wait for the transcript.
- If an interviewee derails into a topic you did not plan for, follow them. The best signal usually comes from a place you did not anticipate. Get back to the script only when the tangent stops producing information.
- Do not skip the retrospective. The main learning of this exercise for most people is not "here is what customers said" — it is **"here is where my interview discipline actually broke down."** Only the retro surfaces that.

## Acceptance criteria

Your submission is complete when:

- [ ] Five interview note files exist, each following the Chapter 6 template, each with editorialising kept in its own section.
- [ ] Every note has a Context section that names the recruiting channel and confirms the ICP fit.
- [ ] Every note has an explicit answer for the three Mom Test diagnostics (recency, action, cost) for the sharpest pain surfaced.
- [ ] The synthesis memo names at least one killed hypothesis with the interview IDs that killed it.
- [ ] The retro memo scores talk ratio, names ≥1 founder-fishing question that slipped, names the best and worst question, and names the recruiting channel that actually worked.
- [ ] All artifacts use the same canonical vocabulary (Chapter 6) — the same noun for the same concept across notes.
- [ ] Every commitment ask you made in the interviews is recorded in the note, with the response.

## Common ways this exercise goes wrong

- **Async DM as a substitute for a call.** Skips the follow-up "why?" mechanic and destroys the exercise. Do not do it.
- **Interviewing people who do not fit the ICP because they are easier to reach.** You have wasted your time and theirs; the notes are unusable. If you cannot find five ICP-fits, write about *why* in the retro — that is the real finding.
- **Notes written from memory a week later.** They are wrong. Same-day is not optional.
- **Skipping the retro.** The retro is where the discipline calibration happens. Without it, you will repeat every mistake in the next batch.
- **Editorialising in the "what they said" section.** Any downstream reader (Exercise 05, project-101) cannot separate fact from interpretation. Keep the editorialising in its own section (Chapter 6).
